- First public release: a native macOS terminal for running many coding agents at once.
- Sidebar groups tabs by project and shows each agent's status, goal and recap; tabs that need you rise to the top, and ⌘J jumps to them.
- Works with Claude Code, Codex, Antigravity, Gemini CLI and Grok through their hooks.
- ⌘P switcher, ⌘O overview, outputs panel (PRs, files, links), reminders with snooze.
- 20 built-in themes plus import from Ghostty, iTerm2, Alacritty, Windows Terminal and base16, with a live-preview picker.
- Resizable sidebar that collapses to a strip of icons or hides; every shortcut can be rebound.
- Optional cheap-model helper for titles, recaps and search by meaning (off by default).
