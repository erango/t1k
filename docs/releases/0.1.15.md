- Separate font sizes for the Mac's screen (13 px) and other displays (14 px). Windows switch as they move between screens, and ⌘+ / ⌘− / ⌘0 change the size for the screen you're on.
- Quitting no longer gets stuck when Claude asks about background tasks: a session still running after its two Ctrl-Cs is hung up, and resumes next launch.
- Each tab's Claude session is saved as soon as it starts or ends, so a crash or force quit still resumes it.
- After a crash or force quit, tabs whose session didn't resume get `claude --resume <id>` typed at the prompt, ready for one Enter.
- Bare domains like sanity.io/manage and email addresses are clickable links.
