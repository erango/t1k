- Tabs now outlive the app. Each tab's shell runs in a small background process, so installing an update, Restart T1K or a crash no longer stops what's running; T1K comes back to the same shells, screens and agents.
- New: Restart T1K in the T1K menu. Your tabs keep running.
- Updates no longer warn that restarting stops your agents, and Restart now is always the default.
- Quitting T1K still ends every tab, as before.
