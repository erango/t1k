- Panes: up to four per tab (⌘D right, ⌘⇧D down), with headers, draggable dividers, ⌘⇧↵ to zoom one, and ⌘⌥ arrows to move between them.
- Panes: an agent in a split pane that asks for you or hits an error shows on its tab's row and in Needs you, with which pane; ⌘J lands on that pane. Closing a pane with a program running asks first.
- Broadcast input: type once into every pane of a tab (⌥⌘I), a group's tabs or tabs you pick. Agent tabs get whole prompts from a compose bar; password prompts pause it and multi-line pastes ask first.
- Tabs sort by when they last changed state, newest first, so rows no longer jump on every status change (group menu › Sort tabs by, to go back to Needs attention).
- Context details: click a Claude tab's context meter for what fills its context window, and Details for the full breakdown, compactions, session totals and loaded tools in the panel's new Context tab.
- Fix: ⌘V with an image on the clipboard (a screenshot, Copy Image) attaches it in Claude Code, as in iTerm2 and Warp.
- Secure Keyboard Entry turns on by itself while the terminal you type in asks for a password (Settings › Advanced to turn that off).
- Outputs: tickets from GitLab, Shortcut, Asana, ClickUp, Trello, Azure Boards, YouTrack, Sentry and self-hosted Jira are listed, each with its mark.
- Watching: a Claude tab that finished its turn but will carry on by itself (background agents, a monitor, a scheduled wake-up) says so, with a countdown, instead of looking done.
