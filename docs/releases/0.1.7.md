- Triggers (Settings › Triggers): when a tab prints a match (including what Claude Code draws), an agent needs you or a command fails, run actions, or ask with buttons and a default after a timeout. Actions include running a command in a new pane, or in the background with its exit status and last lines kept. The helper can write the pattern from a description.
- What you typed but didn't send comes back after a restart: into the shell once its prompt is ready, or into Claude once the session has resumed and shows its input.
- Windows: each shows its name, ⌘O groups tabs by window, the Dock icon brings forward the window that has waited longest, and ⌘Q asks once for every window.
- Outputs: everything but PRs takes one line, the panel can be dragged wider, and the PR section says when status was last fetched, with a refresh for all of them.
- Links can open with a plain click (Settings › Tabs & Links).
- Quick terminal slides in and out, follows the window's opacity, and asks before ⌘W ends its shell.
